
Cuando la auditoría sea de tipo EDITOR y la acción implique modificación:

valor_antiguo ≠ NULL
valor_nuevo ≠ NULL
motivo_cambio ≠ NULL


El sistema no permitirá registrar una modificación sin:

Valor anterior.
Valor nuevo.
Motivo del cambio.


Toda exportación de datos realizada durante una supervisión deberá registrarse como una acción independiente.



Toda acción registrada deberá estar asociada obligatoriamente a una auditoría de supervisión válida.


Los registros de auditoría no podrán ser modificados ni eliminados desde la aplicación una vez finalizada la supervisión.
